# Asistente RRHH · Portal Personas

Asistente de RRHH (chat + Biblioteca de 332 preguntas) en un solo archivo (`index.html`), adaptado al celular.

**Enlace:** https://rrhh-chv.github.io/

## Instalar en el celular
- **iPhone:** abrir el enlace en Safari → Compartir → «Agregar a pantalla de inicio».
- **Android:** abrir el enlace en Chrome → menú ⋮ → «Agregar a pantalla de inicio» / «Instalar app».

## Pendiente antes del uso real
- Reemplazar los correos de ejemplo (`personas@empresa.cl`, `lineaetica@empresa.cl`, `prevencion@empresa.cl`).
- Configurar los enlaces del Portal Personas (`CONFIG_APP.enlaces`).
- Conectar los datos reales del colaborador (hoy muestra «Colaborador Demo»).
- Validar el contenido legal de las respuestas con RRHH / Legal.
